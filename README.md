# WebDatenbankAuswahl

Ein Visual-Studio-Projekt zur Auswahl und Darstellung von Datenbankeinträgen innerhalb einer Webanwendung.

## Beschreibung

Das Projekt **WebDatenbankAuswahl** beschäftigt sich mit den Grundlagen des Datenbankzugriffs in Webanwendungen. Im Mittelpunkt stehen das Abrufen, Auswählen und Anzeigen gespeicherter Daten sowie die Interaktion zwischen einer webbasierten Benutzeroberfläche und einer Datenbank.

## Funktionen

- Verbindung zwischen Webanwendung und Datenbank
- Abrufen gespeicherter Datensätze
- Auswahl bestimmter Datenbankeinträge
- Darstellung von Daten innerhalb einer Webseite
- Grundlagen der Datenbankabfrage und Datenverarbeitung

## Technologien

- Microsoft Visual Studio
- Visual-Studio-Projektmappe (.sln)
- Web- und Datenbanktechnologien

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WebDatenbankAuswahl.git
   ```

2. Die Datei `WebDatenbankAuswahl.sln` in Visual Studio öffnen.
3. Falls erforderlich, die Datenbankverbindung konfigurieren.
4. Das Projekt erstellen.
5. Die Anwendung mit `F5` starten.
6. Die Webanwendung im Browser öffnen.

## Ziel

Das Projekt dient dem Verständnis des Datenbankzugriffs innerhalb einer Webanwendung. Dabei werden grundlegende Konzepte der Datenbankverbindung, Datenauswahl und Darstellung von Datenbankinformationen im Web kennengelernt.
